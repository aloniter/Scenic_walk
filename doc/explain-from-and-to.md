# explain From and To

## What is this?

- `From` is where you start.
- `To` is where you want to go.

## How to use

- Type a clear place name or full address.
- Pick from autocomplete suggestions when possible.

## Good example

- From: `Times Square, New York`
- To: `Central Park, New York`

## Why it matters

- Better input gives better routes.
- If the place is unclear, results can be wrong.
