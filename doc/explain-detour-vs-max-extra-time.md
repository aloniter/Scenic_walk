# explain Detour tolerance vs Max extra time

## They are different

- `Detour tolerance` = distance rule.
- `Max extra time` = time rule.

## Easy way to think

- Detour asks: "How far can I go sideways?"
- Max extra asks: "How many extra minutes can I spend?"

## Best setup to start

- `Detour: Medium`
- `Max extra: +15`

## If you want more places

- Increase both:
- `Detour: High`
- `Max extra: +25`
